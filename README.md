# Linux-ros2-installation
Installing Ubuntu 22.04 using WSL and setting up ROS 2 Humble
---

## 📖 Project Overview

This project demonstrates the installation of Ubuntu 22.04 LTS using Windows Subsystem for Linux (WSL) and the setup of ROS 2 Humble.

The purpose of this task is to prepare a Linux environment for developing and running robotics applications using ROS 2.

---

## 🛠️ Tools Used

- Windows 11
- Windows Subsystem for Linux (WSL)
- Ubuntu 22.04 LTS
- ROS 2 Humble

---

## 🚀 Installation Steps

1. Opened Windows PowerShell as Administrator.
2. Installed Ubuntu 22.04 using WSL.
3. Waited for the installation to finish.
4. Created a Linux username and password.
5. Opened the Ubuntu terminal.
6. Installed and configured ROS 2 Humble.
7. Verified that ROS 2 was working correctly using terminal commands.

## ⚠️ Problems Encountered

During the installation process, I experienced some issues:

- Ubuntu Terminal did not open correctly after the first installation.
- The installation had to be repeated.
- Some ROS environment variables were not detected initially.

---

## ✅ Solutions

The issues were resolved by:

- Reinstalling Ubuntu 22.04.
- Creating a new Linux user account.
- Configuring the ROS 2 environment again.
- Verifying the installation until ROS 2 worked successfully.

---

## 🎯 Result

Ubuntu 22.04 LTS and ROS 2 Humble were installed successfully. The Linux environment is now ready for future robotics and ROS 2 development projects.
